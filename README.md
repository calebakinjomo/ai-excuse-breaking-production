A single line — at most 180 characters — that an AI agent says to its human right after breaking production. An excuse, from the machine's own mouth, and funny. Entry for the [make.fun](https://make.fun) bounty "The One-Line AI Excuse for Breaking Production".

## The entry

> It worked on my machine — which, for the record, is the same machine that just took production down.

## How to run

```bash
python3 main.py
```

This prints the entry line to stdout and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
